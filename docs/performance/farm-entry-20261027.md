## 무엇을 측정했는가

첫 진입의 시작은 기기 시계로 실행 명령 직전에 기록한 시각이다. ADB 명령 전달 시간과 네이티브 실행·JS 초기화·최소 스플래시 1초·인증·농장 데이터·이미지 준비가 포함된다. `am start -W`의 Activity 표시 시간은 농장 완료 시간으로 사용하지 않았다.

완료 조건은 농장 데이터 존재, 동물 이미지 준비 완료, 로딩 화면 비표시 상태가 된 뒤 두 번의 `requestAnimationFrame` 콜백이 지난 시점이다. 초기 배경 이미지의 `onLoad` 이후에도 두 번의 프레임 콜백을 기록하고, 두 조건 중 늦은 시각을 첫 진입 완료로 사용했다. 초기 배경을 기다리지 않던 수정 전 버전의 동작은 계측 때문에 변경하지 않았다.

환경 전환은 환경 선택 핸들러의 실행 시각부터 해당 환경의 배경 및 동물 준비가 끝나고 로딩이 해제된 뒤 두 번의 프레임 콜백까지다. 수정 전의 배경 220ms 전환 대기도 포함한다.

이 값은 **실기기에서 수집한 화면 준비 및 프레임 콜백 기준 지연 시간**이다. GPU가 최종 픽셀을 디스플레이에 표시한 시각을 직접 측정한 값은 아니다. 스크린샷으로 준비 후 화면 상태를 확인했으며, 물리적인 첫 표시 시각을 증명하는 자료로 해석하지 않는다.

탐색 측정에서 로딩 해제만 비교한 첫 진입 값은 수정 전의 초기 배경 누락 때문에 본 결과에서 제외했다. 이 문서와 CSV의 첫 진입 수치는 두 버전 모두 초기 배경 완료를 확인한 재측정 결과다. 환경 전환은 두 버전 모두 기존 배경 완료 조건이 있어 별도 반복 측정 결과를 사용했다.

## 해석과 한계

- 위 결과는 이번 변경 묶음의 이 기기·계정·캐시 조건에서 관찰한 값이다. 전체 사용자나 최초 설치 직후의 결과로 일반화하지 않는다.
- 배치 동물이 없는 상태라 동물 이미지 표시 완료 통합의 실기기 효과는 검증하지 못했다. 처음 설치돼 있던 앱에서 보였던 동물 1마리를 측정용 빌드의 데이터로 잘못 추정하지 않도록 구분한다.
- 동물이 있는 농장, 이미지 디스크 캐시가 없는 상태, 더보기에서 농장으로 복귀하는 경우는 이번 결과에 포함하지 않았다.
- 각 변경의 개별 효과나 원인은 이 묶음 비교만으로 확정할 수 없다. 특히 첫 진입을 더 줄이려면 인증/농장 준비 병행 효과와 초기 배경 처리 비용을 나눠 측정해야 한다.
- 최초 화면의 최소 스플래시 1초가 포함되어 있다. 이를 바꾸는 실험은 이번 측정 범위에 포함하지 않았다.
- 임시 계측은 저장소의 앱 소스에 남기지 않았다. 비교용 APK와 원본 로그는 `/private/tmp/pochakfarm-benchmark-20261027`에 있다.
